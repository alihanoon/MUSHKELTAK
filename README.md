# مشروع مشكلتك (Mushkilatak)

## الفكرة والهدف من المشروع

"مشكلتك" هي منصة إلكترونية متكاملة تهدف إلى تمكين المواطنين في المملكة الأردنية الهاشمية من تقديم وتتبع الشكاوى المتعلقة بالخدمات البلدية والمشاكل العامة في مناطقهم. يسعى المشروع إلى سد الفجوة في التواصل بين المواطن والجهات المعنية (البلديات) لضمان متابعة فعالة وسريعة للمشكلات الميدانية.

### الأهداف الأساسية:

- **تسهيل التبليغ:** تمكين المواطن من إرسال شكوى مدعمة بالصور والموقع الجغرافي الدقيق.
- **الشفافية والمتابعة:** توفير نظام تتبع لحظي لحالة الشكوى (من الإرسال حتى الحل).
- **تحسين الأداء البلدي:** تزويد البلديات بلوحة تحكم شاملة لإدارة الطلبات وتوزيع المهام على الموظفين.
- **التوثيق الرقمي:** أرشفة جميع المعاملات والردود الرسمية لضمان حقوق المواطن والجهة الخدمية.

## نطاق العمل

يركز المشروع بشكل أساسي على:

1. **نظام المستخدمين:** (مواطن، موظف بلدية، مسؤول نظام).
2. **إدارة الشكاوى:** تقديم طلبات جديدة، حفظ مسودات، وتحديث الحالات.
3. **الخدمات البلدية:** تغطية مختلف القطاعات (النظافة، الإنارة، الطرق، الأبنية، الرقابة الصحية).
4. **التواصل:** نظام إشعارات داخلي وتواصل عبر البريد الإلكتروني عند تحديث حالة الطلب.

## التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** React.js مع TypeScript و Tailwind CSS للتصميم.
- **الواجهة الخلفية (Backend):** Node.js مع Express.
- **قاعدة البيانات:** MongoDB (عبر Mongoose).
- **إدارة الحالة والأنيميشن:** Motion (Framer Motion سابقاً).
- **الأيقونات:** Lucide React.

## طريقة التشغيل (Setup & Run)

### المتطلبات الأساسية:

- وجود **Node.js** مثبت على الجهاز.
- قاعدة بيانات **MongoDB** (محلياً أو عبر MongoDB Atlas).

### الخطوات:

1. **تثبيت المكتبات:**

   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   قم بإنشاء ملف `.env` في المجلد الرئيسي وأضف القيم التالية:

   ```env
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   ```

3. **تشغيل المشروع في بيئة التطوير:**

   ```bash
   npm run dev
   ```

   سيقوم هذا الأمر بتشغيل الخادم (Backend) ودمج Vite لخدمة الواجهة الأمامية على المنفذ `3000`.

4. **بناء المشروع للإنتاج:**
   ```bash
   npm run build
   ```

## هيكلية المستخدمين في النظام

- **المواطن:** يمكنه تقديم الشكاوى، تتبعها، والبحث عن معاملات سابقة.
- **الموظف:** يمكنه رؤية الشكاوى الواردة في منطقته وتحديث حالتها وإضافة ردود رسمية.
- **المسؤول (Admin):** يمتلك كامل الصلاحيات لإدارة المستخدمين، الموظفين، والاطلاع على الإحصائيات العامة للنظام.
